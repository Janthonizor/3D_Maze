# 3D_Maze
A tubular maze game

Generate a spanning tree in a cubic lattice of nodes based on a random seed. 

# Level Generation 
User inputs N, and seed to generate a new level. If no seed is selected the seed becomes the time at request of level generation. 


# mesh dimensions
Sphere: 1.0
hole_width: 0.6
wall thickness: 0.05
round cube arc: 32
cylinder arc: 64
